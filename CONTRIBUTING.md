# Contributing

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-organization/your-repo-name.git
   cd your-repo-name
   ```

2. Create a virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Development

- Run tests: `pytest`
- Lint: `ruff check .`
- Format: `ruff format .`
